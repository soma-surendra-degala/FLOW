# 🌊 FLOW – Modern Learning Management System (LMS)

**FLOW** is a modern, scalable, and interactive **Learning Management System (LMS)** built using the **MERN stack** with **Angular** as the frontend framework.  
It provides a seamless experience for students and administrators to manage courses, practice problems, internships, and careers — all from one place.

---

## 🎯 Objectives

- **Simplify Learning Management:** Deliver an intuitive and easy-to-use LMS for institutions and organizations.  
- **Centralized Administration:** Empower admins to manage courses, students, and analytics through one dashboard.  
- **Enhance Student Experience:** Provide progress tracking, discussions, and real-time updates.  
- **Ensure Reliability & Security:** Use secure, scalable, and future-ready architecture with JWT authentication.

---

## 👥 Target Users

- **Admins / Institutions:** Manage users, courses, practices, support, notifications, and careers.  
- **Students / Learners:** Access courses, solve practice problems, track progress, and apply for internships or careers.

---

## 🚀 Key Features

### 🧑‍🎓 Student Portal
- Personalized dashboard with real-time activity tracking  
- Access to enrolled courses, upcoming sessions, and practice sets  
- Integrated coding practice environment (multi-language support)  
- Course videos (YouTube integration) and downloadable materials  
- Discussion forum (via Telegram) for collaboration  
- Profile management and progress tracking  
- Helpdesk for submitting and tracking support tickets  
- Career section for job/internship opportunities  

### 🧑‍💼 Admin Portal
- Secure login with JWT authentication  
- Manage courses, practices, students, and careers  
- Track student activities and course progress  
- Manage notifications, support tickets, and system updates  
- Real-time analytics and performance insights  

---

## 🧱 Tech Stack

| Layer | Technology |
|-------|-------------|
| **Frontend** | Angular + Tailwind CSS |
| **Backend** | Node.js + Express.js |
| **Database** | MongoDB (MongoDB Atlas) |
| **Authentication** | JWT (JSON Web Token) |
| **Storage** | Cloudinary (for documents & media uploads) |
| **Hosting** | Frontend: Netlify · Backend: Render |

## 🖥️ System Modules

### 1. **Landing Page**
- Header navigation, hero section, about, core values, internships, services, testimonials, and contact form.

### 2. **Student Dashboard**
- Overview widgets for Courses, Practices, and Upcoming Courses.
- Notification panel and Telegram group link for discussion.

### 3. **Courses Module**
- Watch videos (embedded player), download course documents, and track enrolled courses.

### 4. **Practice Module**
- Coding exercises with multi-language IDE (C, C++, Java, Python, JS, TS, etc.).
- Run, test, and submit solutions.
- View official solutions.

### 5. **Upcoming Courses**
- View upcoming course schedules and enroll with one click.

### 6. **Profile Management**
- Update academic, personal, and contact details.

### 7. **Support / Help Desk**
- Create, view, and track issue tickets.
- Admin responses with status updates.

### 8. **Career Section**
- Browse job openings with detailed info.
- Apply directly through external links.

## 🧑‍💼 Admin Modules

| Module | Description |
|--------|-------------|
| **Dashboard** | View total courses, students, issues, and real-time activity logs |
| **Manage Courses** | Add, edit, or delete course content, videos, and documents |
| **Manage Practice** | Add and manage coding exercises with difficulty and solutions |
| **Upcoming Courses** | Schedule and manage upcoming course entries |
| **Students** | View and edit student profiles and details |
| **Support** | Respond to student issues and track their status |
| **Notifications** | Create, edit, and delete platform-wide notifications |
| **Careers** | Post job/internship openings and manage listings |
